# MovieOS 웹 가이드 디자인

- 웹페이지는 영상 제작 요청의 필수 산출물이다. 초반 질문(첫 프레임 생성 여부, 씬별 추가 관련 이미지 수량, 실제 부모 폴더 경로 포함)의 답변이 끝나면 추가 선택이나 요청 없이 `index.html` 생성·브라우저 열기·표시 확인까지 진행한다.
- 기준 외형 확인을 사용자가 명시적으로 요청한 경우에도 현재 대본과 기준 이미지를 담은 페이지를 먼저 제공한다. 일반 제작 요청에는 별도 외형 승인 대기를 추가하지 않는다.
- 선택한 모든 씬의 첫 프레임·관련 이미지와 별도 썸네일을 실제 파일로 연결한다. 첫 프레임은 선택에 따라 씬당 0장 또는 1장, 추가 관련 이미지는 씬당 N장이다. 0장으로 선택한 종류는 빈 칸이나 실패로 표시하지 않는다. 요청한 이미지의 생성 실패나 누락은 완료로 표시하지 않는다. 생성된 이미지에는 원본 열기·다운로드를 제공한다.
- 로컬 브라우저에 페이지를 열어 전체 이미지 로딩과 대표 씬의 표시를 확인하고 링크를 전달한다. 영상·음성의 생성 여부는 이미지·웹페이지 완료와 따로 표시한다.

사용자가 제공한 toss-light.md의 시각 토큰을 제작 가이드에 적용한다. 첨부 자료의 금융 UI·브랜드 주장·예시 계좌는 재현하지 않는다. 원본 파일이나 개인 경로에 의존하지 않고 동봉한 assets/toss-light.css를 사용한다.

- 흰 배경 #FFFFFF, 보조 면 #F2F4F6, 본문 #191F28, 보조 글 #4E5968, 경계 #E5E8EB, 강조 #0064FF.
- Pretendard가 설치되어 있으면 사용하고 Apple 시스템 한글 글꼴로 폴백한다. 전용 Toss 글꼴이나 외부 CDN 다운로드를 요구하지 않는다.
- 12~16px 둥근 카드, 거의 없는 그림자, 4px 단위 여백, 본문 17px/1.65/500, 제목 32px·24px·19px 위계.
- 제작 가이드의 이미지 비교를 위해 데스크톱 최대 폭 1120px, 모바일 좌우 20px. 시트 전체를 object-fit:contain으로 보여주고 원본을 다운로드할 수 있게 한다.
- 글자 없는 썸네일 → 개요 → 제목 5개·태그 포함 설명 → 후킹 배치도 → 전체 나레이션 음성변환용 코드블록 → 캐릭터 시트 → 씬별 가이드.
- 씬별 발화는 22~26px, 굵기 600, 줄높이 1.7, 충분한 문단 간격. 코드블록처럼 고정폭 글꼴로 표시하지 않는다.
- 전체 나레이션 코드블록에는 실제 대사만 넣는다. 복사 버튼은 textContent를 복사하고 성공 후에만 완료로 표시한다. 실패 시 수동 선택 안내를 제공한다.
- 모델 정보는 짧은 배지·설명으로 보이며 상세 지원표는 접을 수 있게 한다. API 지원과 실제 Flow 계정 UI 확인을 구분한다.

- 씬 1~N 연속 번호로 통일한다. 각 씬 제목 바로 아래에 읽기용 나레이션을 둔다. 다음 영문 영상 프롬프트는 기본 펼침, 한국어 영상 프롬프트는 기본 접힘으로 둔다. ‘나레이션 먼저 읽기’와 하단 전체 대본 중복은 만들지 않는다.
- 후킹 배치도는 시간·씬 링크·화면 내용·이유를 보여주는 반응형 HTML 흐름도를 사용한다. YouTube 설명에 논문 주소는 넣지 않는다.

- 저장 경로는 이번 프로젝트 초반에 사용자가 입력한 실제 부모 경로 아래 `<영상명>/`이다. 과거 경로나 현재 폴더로 자동 대체하지 않는다. 썸네일·선택한 첫 프레임·관련 이미지와 HTML·스타일·대본·프롬프트가 이 폴더 안에 저장된다고 저장 위치 질문에서 설명한다. 상대 경로를 사용한다.
- 작품 개요에 첫 프레임 생성 여부와 씬별 추가 이미지 수량을 표시한다. `첫 프레임 이미지` / `관련 이미지 1…N`을 실제 수량에 맞춘 반응형 격자로 배치한다. 한 장이면 단일 카드, 두 장 이상이면 나란히 비교할 수 있게 하며, 모두 0장이면 해당 씬의 이미지 영역을 생략하고 나레이션·영상 프롬프트를 유지한다.
- 각 관련 이미지의 시점과 설명 방식 차이를 한 줄로 적는다. 첫 프레임이 없으면 기본 구도·기준 시트와 다른 관련 이미지를 비교 기준으로 삼는다. 단순 크롭·색 변경으로 보조 이미지를 대체하지 않는다.
- 완료 직전 직접 재검수한다: 지정 폴더의 `index.html` 존재, 씬별 선택 수량 일치, 이미지 상대 경로, 전체 이미지 로딩, 대표 씬 표시, 복사 동작, 모바일 넘침을 확인하고 최종 응답에 가이드 링크를 제공한다. 누락은 수정한 뒤 마친다. 검수를 별도 승인이나 멀티에이전트 리뷰 관문으로 만들지 않는다.
