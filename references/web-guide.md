# MovieOS 웹 가이드 디자인

사용자가 제공한 toss-light.md의 시각 토큰을 제작 가이드에 적용한다. 첨부 자료의 금융 UI·브랜드 주장·예시 계좌는 재현하지 않는다. 원본 파일이나 개인 경로에 의존하지 않고 동봉한 assets/toss-light.css를 사용한다.

- 흰 배경 #FFFFFF, 보조 면 #F2F4F6, 본문 #191F28, 보조 글 #4E5968, 경계 #E5E8EB, 강조 #0064FF.
- Pretendard가 설치되어 있으면 사용하고 Apple 시스템 한글 글꼴로 폴백한다. 전용 Toss 글꼴이나 외부 CDN 다운로드를 요구하지 않는다.
- 12~16px 둥근 카드, 거의 없는 그림자, 4px 단위 여백, 본문 17px/1.65/500, 제목 32px·24px·19px 위계.
- 제작 가이드의 이미지 비교를 위해 데스크톱 최대 폭 1120px, 모바일 좌우 20px. 시트 전체를 object-fit:contain으로 보여주고 원본을 다운로드할 수 있게 한다.
- 글자 없는 썸네일 → 개요 → 제목 5개·태그 포함 설명 → 후킹 배치도 → 전체 나레이션 음성변환용 코드블록 → 캐릭터 시트 → 씬별 가이드.
- 씬별 발화는 22~26px, 굵기 600, 줄높이 1.7, 충분한 문단 간격. 코드블록처럼 고정폭 글꼴로 표시하지 않는다.
- 전체 나레이션 코드블록에는 실제 대사만 넣는다. 복사 버튼은 textContent를 복사하고 성공 후에만 완료로 표시한다. 실패 시 수동 선택 안내를 제공한다.
- 모델 정보는 짧은 배지·설명으로 보이며 상세 지원표는 접을 수 있게 한다. API 지원과 실제 Flow 계정 UI 확인을 구분한다.

- 씬 1~N 연속 번호로 통일한다. 각 씬 제목 바로 아래에 읽기용 나레이션을 둔다. 다음 영문 영상 프롬프트는 기본 펼침, 한국어 영상 프롬프트는 기본 접힘으로 둔다. ‘나레이션 먼저 읽기’와 하단 전체 대본 중복은 만들지 않는다.
- 후킹 배치도는 시간·씬 링크·화면 내용·이유를 보여주는 반응형 HTML 흐름도를 사용한다. YouTube 설명에 논문 주소는 넣지 않는다.
