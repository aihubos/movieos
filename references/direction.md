# 화풍과 연기 참고

## 지브리풍 선택 시

Studio Ghibli-inspired hand-drawn 2D cel animation, classic 1980s–1990s line art, painted gouache and watercolor backgrounds, expressive restrained faces, organic multiplane depth, soft natural highlights and pastel greens, blue-grays and sunset hues.

전경·중경·후경을 분리하고 바람에 머리와 옷이 반응하게 한다. 절제된 신체 움직임, 수평 패닝·트래킹 중 하나 또는 고정을 사용한다. 3D CGI, 디지털 플라스틱 광택, 플랫한 웹툰, 극단적 네온, 과한 실사 렌즈 왜곡을 배제한다. 전통 복식과 자연 풍경은 스토리에 맞을 때만 쓴다.

## 실사 선택 시

시네마 구도에 맞는 화각, 인물·배경의 초점 관계, 자연스러운 피부와 하이라이트, 빛 방향을 구체적으로 쓴다. 카메라 브랜드명만으로 룩을 설명하지 않는다. 감정 클로즈업은 배경 분리, 공간 관계가 중요하면 깊은 초점을 고려한다. 카메라 움직임은 하나로 제한한다. 셀 라인이나 수채화 질감을 실사에 자동 적용하지 않는다.

실사 프롬프트에는 장면 의도에 맞는 화각·초점거리 느낌, 조리개 또는 초점 깊이, 이동 하나, 조명 방향, 색·명암·질감을 함께 적는다. 장비의 정확한 복제나 생성 성능 보장으로 표시하지 않는다. 구체적인 활용 절차는 `reference-use.md`의 카메라 항목을 따른다.

## 다른 화풍 선택 시

매체, 선, 표면 질감, 색상, 깊이 표현, 동작 원리를 짧게 정의해 전 씬에 유지한다. 지브리풍의 3D 배제 규칙을 스톱모션·3D 등 다른 선택 화풍에 잘못 적용하지 않는다.

## 연기 DNA

- 정적 응시: 몸을 작게 유지하고 시선과 호흡으로 감정을 드러낸다.
- 멈춤: 중요한 대사 앞뒤에 판단과 망설임을 위한 침묵을 둔다.
- 속도 변화: 인물의 고정 말 속도보다 상황과 감정 변화에 맞춘다.
- 문장 끝: 모든 문장을 강하게 끝내지 않고 핵심 의도에 힘을 준다.
- 동작 반응: 의미 있는 몸동작만 남긴다. 무조건 8초에 한 번으로 고정하지 않는다.

이는 사용자 참고 자료에서 요약한 연출 원리이며 배우별 실측 결과의 검증을 뜻하지 않는다. 문서의 예시 초 수와 순위는 절대 규칙이 아니다.

## 모델 지원 확인

후보명 Gemini Omni Flash 1.1 및 Veo 3.1 - Fast, 후보 길이 4/6/8/10초는 사용자가 제시한 제작 희망값이다. 이 파일은 지원표가 아니다. 실제 제작 때 공식 문서나 사용 중인 서비스의 현재 선택 화면으로 이름과 모델·모드·길이·해상도 조합을 확인한다. 확인 날짜와 출처를 scenes.md에 한 번 기록한다. 확인이 안 되면 계획을 작성할 수 있지만 확정 지원값처럼 출력하지 않는다.

## 씬별 Veo·Omni 추천

- 공식 문서: https://ai.google.dev/gemini-api/docs/video , https://ai.google.dev/gemini-api/docs/omni , https://ai.google.dev/gemini-api/docs/veo
- 추천 이유는 해당 씬의 작업에 연결한다. 여러 입력을 함께 지시하거나 동작 관계를 반복 수정할 경우 Omni를 검토한다. 기존 Veo 첫 프레임 제작을 이어가거나 끝 프레임·연장 작업이 필요한 경우 Veo를 검토한다. 지원 범위는 제작 시점에 재확인한다.
- 과학 시각화의 정확성, 인체·생물 형태 일관성, 정해진 초 단위 동작은 어느 모델도 이름만으로 보장하지 않는다. 과학 장면에 Omni를 추천해도 실제 결과를 원리와 대조한다.
- 챕터 내 모델 선택 예시: 기포 시각화 씬은 Omni, 기존 동물 첫 프레임을 움직이는 씬은 Veo. 각 씬에 선택 이유를 표시한다.
- RECOMMENDED MODEL과 TARGET MODEL을 구분한다. 추천을 적용한 경우 씬 카드도 갱신하며, 변경하지 않았다면 기존 TARGET MODEL과 추천의 차이를 설명한다. 다른 모델의 길이·모드 지원을 그대로 복사하지 않는다.
