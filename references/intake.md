# 질문·답변 저장과 복구

전체 제작의 필수 선택을 받을 때 읽는다. 텍스트만 요청했으면 필요한 대본 정보만 받는다. 현재 요청이 스킬 수정이면 영상 제작 질문을 시작하지 않는다.

## 한 질문의 수명

1. 이번 요청에 이미 있는 선택을 반영한다. 질문이 남으면 **질문 저장 → 질문 하나 표시 → 실제 답변 대기 → 해당 답 저장** 순서로 처리한다. 저장된 답이 있어야 다음 질문으로 넘어간다.
2. 추천값·도구의 미리 선택된 값·무응답·시간 경과·취소·창 닫힘은 답변이 아니다. 별도 자료 점검이나 상태 질문도 선택으로 처리하지 않는다.
3. 사용자에게 한 번에 **한 항목의 번호 있는 선택지**만 보여준다. 추천 이유는 한 줄로, 직접 입력도 허용한다. 여러 결정을 한 선택지에 섞지 않는다. 자발적으로 여러 답을 주면 모두 반영한다.
4. 숫자만 온 답은 마지막으로 실제 표시한 미응답 질문의 선택 번호다. `2`와 `2장`을 구분한다. 이전 카드 ID가 붙은 답은 그 질문에만 대응한다. 중단 후 어느 질문의 번호인지 알 수 없으면 값을 추측하지 않고 저장된 질문 하나를 복구한다.
5. “안 보여”, “다시 보여줘”, 취소·중단 후 재개는 **같은 ID·번호·순서·의미의 질문**을 다시 연다. 다른 질문을 만들거나 받은 답을 초기화하지 않는다. 이미 답한 질문의 중복 응답은 다음 질문에 적용하지 않는다.
6. “화풍은 2번으로 바꿔줘”처럼 수정 대상이 명확하면 그 항목만 수정하고 현재 다른 미응답 질문은 유지한다. 필수 선택이 모두 있으면 질문을 추가하지 않고 제작으로 전환한다.

## 표시 수단 선택

앱의 임시 질문 창을 유일한 기록으로 삼지 않는다. 스킬은 앱의 카드 수명·렌더링이나 내부 추론 설정을 제어하지 못하므로 앱 오류를 수정했다고 주장하지 않는다.

- **본문 객관식이 허용됨:** final에 직전 답 확인 한 줄, 현재 질문과 번호·설명 전체, 질문 카드 링크를 남긴다. 질문 도구는 불필요하다. commentary만으로 질문을 끝내지 않는다.
- **상위 지침이 질문 도구를 요구하거나 본문 객관식을 금지함:** 도구의 사용 가능 모드와 필수/선택 입력 제한을 먼저 따른다. 허용된 경우 아래 도구 절차를 사용한다. 필수 입력에 도구 사용이 허용되지 않으면 짧은 직접 질문과 카드 링크를 final에 남긴다. 카드에 모든 객관식 선택지를 둔다.
- **동기 질문 도구:** 저장된 카드와 같은 질문 하나를 전달하고 반환된 실제 답을 반영한다. 도구 호출 자체를 답변으로 처리하지 않는다.
- **비동기 질문 도구:** 질문 카드를 저장·열고 질문 하나를 호출한 뒤 입력을 기다린다. **호출 직후 final로 강제 종료하지 않는다.** 환경이 지원하는 입력 대기/양도를 사용하고, 대기 중 조사·제작·새 질문을 시작하지 않는다. 제한 때문에 턴을 마쳐야 하면 현재 카드 링크를 남기고 미응답 상태를 유지한다. 같은 질문 도구를 반복 호출하거나 임의의 시간 경과로 선택을 확정하지 않는다.
- 도구에 자동 제공되는 자유 입력 칸은 중복 선택지로 만들지 않는다. 도구와 카드의 실제 선택 번호·의미를 맞춘다. 도구의 항목 수 제한 때문에 줄여야 하면 질문을 저장하기 **전에** 후보를 줄이고, 직접 입력으로 나머지 값을 받을 수 있게 한다.
- 파일 패널이 있으면 질문 카드 파일을 연다. 파일 패널 열기 실패로 질문 표시를 막지 않는다. 모든 경로는 사용자에게 클릭 가능한 절대 경로 링크로 제공한다. 카드 저장이 불가능하면 제한을 알리고 허용된 본문/도구에 질문 전체를 남긴다.

## 저장 도우미

`scripts/intake.py`는 Python 표준 라이브러리만 사용한다. 필수 선택의 완료 여부나 사용자 의도는 에이전트가 판단한다. 도우미는 질문 ID, 선택 번호·값, 입력 형식, 이전 답의 보존을 담당한다. 한 세션은 담당 에이전트 하나만 기록한다.

- 세션 폴더는 앱이 제공한 **현재 작업의 허용된 산출물 경로** 아래 충돌 없는 `movieos-intake-<세션 식별자>/`로 만든다. 이것은 임시 질문 기록이며 영상의 저장 부모 경로를 확정하지 않는다. 스킬 저장소·설치 폴더나 과거 영상 폴더에 세션을 저장하지 않는다.
- `state.json`이 기준 기록, `Q001-<항목>.md` 등이 보존되는 질문 카드, `current.md`가 최신 선택 현황이다. 질문마다 카드 링크를 대화에 남긴다. 카드가 사라져도 `show`로 다시 만든다. 손상된 상태 파일을 빈 세션으로 자동 초기화하지 않는다.
- 실행 파일은 읽은 스킬 폴더를 기준으로 찾는다. 입력 JSON은 도구의 파일 쓰기 또는 따옴표 있는 heredoc으로 전달한다. 사용자 경로나 대사를 셸 명령에 그대로 삽입하지 않는다.

```bash
python3 /absolute/skill/scripts/intake.py /absolute/session ask <<'JSON'
{"field":"first_frame","title":"각 씬별 첫 번째 프레임 이미지를 생성할까요?","options":[{"label":"생성함 — 씬마다 1장","value":true},{"label":"생성 안 함 — 씬마다 0장","value":false}]}
JSON
```

명령 | stdin JSON | 적용
---|---|---
`ask` | 위의 `field`, `title`, `options` | 질문 ID 자동 부여. 미응답 질문 교체 금지. 같은 입력 재호출은 같은 ID 유지
`answer` | `{"question_id":"Q001-first_frame","option":2}` | 실제 답변의 선택 번호 반영. 오래된 ID·범위 밖 번호 거부
`answer` | `{"question_id":"현재 ID","value":3}` | 직접 입력된 실제 값 반영. 수량의 `0`과 첫 프레임 `false`도 확정값
`record` | `{"answers":{"duration":"45초","related_images":0}}` | 사용자가 먼저 제공한 값·여러 답·명확한 수정만 반영. 미응답인 다른 항목 유지
`show` | 없음 | 저장 상태·현재 질문 확인, 카드 복구. 새 질문을 생성하지 않음

질문 선택지의 `value:null`은 “직접 입력”이다. 해당 번호만 고르면 확정되지 않는다. 실제 값을 받은 뒤 `answer`의 `value`로 저장한다. 전체 경로 없는 저장 위치, 음수·소수 이미지 수량은 저장하지 않는다. 어떤 명령도 기본값을 선택하거나 제작을 시작하지 않는다.

## 미응답 질문 순서

순서 | 항목 키 | 선택지·규칙
---|---|---
1 | `video_type` | 쇼츠 / 정보성 유튜브 / 스토리가 있는 영상. 이미 명시한 유형은 유지
2 | `purpose` | 지식 전달·이해 / 흥미·발견 / 홍보·설득 / 감정·스토리
3 | `duration` | 쇼츠는 30·45·60·90초 중 2~3개와 추천 이유. 긴 영상은 분 단위 후보. 직접 정한 길이는 그대로 유지
4 | `story` | 이야기가 없을 때만 후보 2~3개와 아이디어 직접 입력. 기존 훅·핵심 설정 보존
5 | `style` | 이야기와 맞는 화풍 2~3개와 이유. 기본 화풍으로 임의 확정하지 않음
6 | `language` | 실제 발화 한국어 / 영어. 프롬프트 언어와 별개
7 | `first_frame` | “각 씬별 첫 번째 프레임 이미지를 생성할까요?” 생성함(true) / 생성 안 함(false)
8 | `related_images` | “첫 프레임과 별도로, 각 씬별 관련 이미지를 몇 장 생성할까요?” 0장 / 1장(추천: 원리 보조) / 2장 / 직접 정수 입력
9 | `parent_path` | “영상명 폴더를 만들 상위 폴더를 선택해 주세요.” 확인 가능한 후보의 **전체 경로**와 다른 경로 직접 입력

- 추가 이미지 수는 **씬마다** 적용한다. 씬별 별도 지정은 `{"1":0,"2":2}`처럼 보존하고, 아직 없는 씬의 수량을 임의로 추정하지 않는다. 첫 프레임·썸네일·기준 시트는 추가 이미지 수량에 포함하지 않는다.
- 저장 위치에는 “선택하거나 입력한 경로 아래에 영상명 폴더를 만들고, 썸네일·선택한 씬 이미지·대본·프롬프트·웹 가이드를 저장합니다.”를 설명한다. 경로 없는 “기존 폴더”나 직접 입력 선택만으로는 미완료다. 과거 경로·현재 작업 폴더는 후보로만 쓰고 자동 확정하지 않는다.
- 사용자 경로를 받기 전에는 프로젝트 파일·이미지를 만들지 않는다. 모든 선택 후 실제 `<부모 경로>/<영상명>/`을 안내한다. 사용자에게 보여준 후보 경로만 번호와 대응시킨다.
- 화면비는 유형과 별개다. 명시한 화면비를 유지하며, 미지정 기본은 16:9·중앙 안전 구도·목표 1080p다. 화면비 확인이 필요하면 `aspect_ratio` 질문 하나를 별도로 받는다.
- 질문 중에는 예상 씬 수 계산·주제 조사·참고 ZIP 분석·대본 설계·모델 비교·이미지 생성·에이전트 호출을 하지 않는다. 질문에 필요한 저장 후보 확인과 질문 파일 기록만 한다. 같은 스킬·메모리를 답변마다 재독하지 않는다.
- 텍스트만 요청하면 화풍·이미지·저장 위치를 위한 질문을 만들지 않는다. 대본의 주제·분량·발화 언어 등 실제로 필요한 미응답 정보만 확인한다. “나레이션만”이면 순수 발화 코드블록으로 완료한다.
